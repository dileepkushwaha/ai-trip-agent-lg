### 3. ✅ **Round Trip Option**

#### UI Implementation:

**Round Trip Checkbox**:
```python
is_round_trip = st.checkbox("🔄 Round Trip", value=False)
```

**Conditional Return Fields**:
```python
if is_round_trip:
    return_date = st.date_input("Return Date")
    return_time = st.time_input("Return Time")
```

**Features**:
- Toggle round trip on/off
- Return date/time only shown when enabled
- Validation (return after departure)
- Clear visual indication

#### Backend Integration:

**State Schema**:
```python
is_round_trip: bool  # Whether it's a round trip
return_date: Optional[str]  # Return date (if round trip)
return_time: Optional[str]  # Return time (if round trip)
```

**API Model**:
```python
is_round_trip: bool = Field(False, description="Whether it's a round trip")
return_date: Optional[str] = Field(None, description="Return date (YYYY-MM-DD)")
return_time: Optional[str] = Field(None, description="Return time (HH:MM:SS)")
```

## 🚀 How to Use

### Date and Time Selection

1. **Open Main App**: http://localhost:8516

2. **In Sidebar**:
   - Scroll to "📅 Travel Date & Time"
   - Select departure date from calendar
   - Select departure time from picker
   - Optionally check "🔄 Round Trip"
   - If round trip, select return date/time

3. **Plan Trip**:
   - Enter your query
   - All date/time info is included
   - Agent uses this for scheduling

### Round Trip

1. **Enable Round Trip**:
   - Check "🔄 Round Trip" checkbox
   - Return date/time fields appear

2. **Set Return Details**:
   - Select return date (must be after departure)
   - Select return time
   - System validates dates

3. **Trip Planning**:
   - Itinerary includes both journeys
   - Carbon footprint for round trip
   - Separate recommendations for each leg

### Observability Dashboard

1. **Access Dashboard**:
   - Click "📊 Observability" in header
   - Dashboard opens in new page

2. **Monitor System**:
   - View API health status
   - Check LLM and DB connections
   - See version information

3. **Monitor Agents**:
   - View all active agents
   - See agent details and metrics
   - Check recent updates
   - Monitor duration and status

4. **Auto-Refresh**:
   - Enable auto-refresh in sidebar
   - Set refresh interval
   - Dashboard updates automatically

5. **Return to Main App**:
   - Click "🏠 Back to Main App"
   - Returns to trip planning

### Common Questions

A: Date/time is optional. System works without it.

A: Check "🔄 Round Trip" box, then select return date/time.
